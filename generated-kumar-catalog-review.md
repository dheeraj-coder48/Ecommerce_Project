## Import status and pricing note

This is a development/demo catalog. **₹999 and stock 10 are temporary development defaults, not verified retail prices or real inventory. Replace both with confirmed values before production sales.** The project Sanity dataset is `production`; the site can display and sell published products from this dataset.

The 22 products were published to the configured `production` dataset as requested. They are visible and currently have the temporary values above; replace prices and stock before accepting real customer orders.

Generated 22 unique men's ethnic product documents from 36 useful image files. Related views are grouped into single products. Promotional artwork, bundle offers, and ads marked “Gents | Kids” are excluded. No fabric composition or available sizes are asserted because the source photos do not establish them.

The schema has a single description field, so short and detailed copy are combined in that field. It has no tags, separate occasion, or fit field. Product category references use the existing category schema and men's department. The four category records below are added only when a matching usable category does not already exist.
